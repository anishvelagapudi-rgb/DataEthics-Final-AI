# [APP NAME] — AI-Powered Misinformation Detection

A fictional product concept and accompanying website created for the **Data Ethics & AI** course (Spring 2026).

## About

This project imagines a browser extension and mobile app that uses AI to detect misinformation patterns in news articles, data visualizations, and video content in real time. The product, app name, and all described features are **entirely fictional** — this is a design and ethics exercise, not a real product.
