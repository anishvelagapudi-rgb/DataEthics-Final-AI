# TruthLens — AI-Powered Misinformation Detection

A product concept and accompanying website created for the **Data Ethics In The Age Of AI** course (Ms. Cantwell, Spring 2026).

## About

TruthLens is a proposed AI-powered browser extension and mobile app that scans news articles, videos, charts, and social media content in real time. It identifies misleading framing, distorted statistics, manipulated graphs, and missing context — then explains the manipulation tactic to the user in plain language. The goal is not just fact-checking, but building media literacy.

The product and all described features are **a design and ethics exercise, not a real deployed product.**
